# План тренировки

Итоговое задание по модулю 2, вариант 11. Автор — allagardo.

Введите название упражнения, число подходов от 1 до 5 и число повторений в первом подходе (хотя бы 1). Дальше в каждом подходе на 2 повторения больше. Программа показывает таблицу, сумму, среднее и нагрузку.

Если всего меньше 30 повторений, нагрузка небольшая. От 30 до 60 включительно — средняя. Больше 60 — высокая.

После отчёта введите «да» для новой тренировки или «нет» для выхода.

## Запуск

Откройте папку в PyCharm, выберите Python 3 и запустите `src/main.py`.

Можно запустить и из папки проекта командой `python src/main.py` (на Windows также `py -3 src/main.py`).

## Что есть в коде

Название и ответы хранятся в `str`, число повторов — в `int`, среднее — во `float`. Переменная типа `bool` показывает, нужно ли считать новую тренировку.

`if`, `elif` и `else` выбирают нагрузку. `and` и `or` нужны для проверки ввода. Цикл `for` с `range()` считает повторы, а `while` повторяет ввод и расчёт. Функции возвращают результаты через `return`, а f-строки выравнивают таблицу.

Константа модуля `REPETITIONS_INCREMENT` задаёт прибавку в 2 повторения. Локальные переменные `total` и `average` хранят сумму и среднее за подход.
